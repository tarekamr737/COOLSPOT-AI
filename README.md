# COOLSPOT AI

COOLSPOT AI turns cached FortyGuard heat intelligence and authoritative Pacoima public data into
a deterministic, budget-constrained cooling-investment plan. The demo exposes heat, persistence,
exposure, and vulnerability layers; ranked candidate sites; grounded evidence; uncertainty; and
claim-safe explanations.

The deployed container runs in cached demo mode. Changing the planning budget does not call
FortyGuard or spend vendor credits.
